## Analysis

The reliable transfer works because each packet carries a checksum, a sequence number, and a cumulative ACK. The checksum lets the receiver discard corrupted data silently, which makes corruption behave like a loss. Sequence numbers allow the receiver to detect duplicates or out-of-order packets and keep the logic simple by acking only the next expected value. The sender then uses cumulative acknowledgments and a timer to recover from missed packets by retransmitting from the oldest unacknowledged point.

The Go-Back-N window matters because it improves throughput by allowing multiple packets to be in flight at once. With a small window, the sender spends more time idle waiting for ACKs, while a larger window keeps the channel busy and amortizes the propagation delay. The timer is essential because loss is silent; without a timeout, the sender would never know to retransmit a dropped or corrupted packet.

Overall, the exercise demonstrates why TCP uses checksums, sequence numbers, cumulative ACKs, timeouts, and sliding windows: these mechanisms turn an unreliable datagram service into a reliable, ordered byte stream.

## Results

Each configuration transferred a 1 MiB random file three times through the relay with `--delay 50` and the default 250 ms retransmission timeout. Every received copy was checked against the source with `cmp`; all 12 comparisons were identical.

| Window | Loss | Mean time (s) | Throughput (KiB/s) |
|-------:|-----:|--------------:|-------------------:|
| 1 | 0% | 103.835 | 9.86 |
| 16 | 0% | 6.708 | 152.66 |
| 1 | 5% | 128.055 | 8.00 |
| 16 | 5% | 25.853 | 39.61 |

For window 1 with no loss, the sender took an average of 103.835 seconds for 1,025 packets, or about **101.3 ms per round trip** (`103.835 / 1,025`). The relay contributes 100 ms, leaving roughly 1.3 ms for endpoint work: packet encoding and checksum calculation, socket and kernel processing, scheduling, polling, and timer granularity.

Increasing the window to 16 reduced the no-loss mean from 103.835 seconds to 6.708 seconds, a **15.5× speedup**, close to the ideal 16×. Multiple packets can now be in flight during each round trip, so the sender spends much less time waiting. The remaining difference from 16× comes from protocol and operating-system overhead, the finite transfer/window boundaries, and cumulative ACK timing.

With 5% loss, window 1 increased from 103.835 to 128.055 seconds (about 1.23×); window 16 increased from 6.708 to 25.853 seconds (about 3.85×). A stop-and-wait timeout retransmits only its one outstanding packet. With Go-Back-N, a lost packet holds back the cumulative ACK, and a timeout retransmits the whole outstanding window, including packets that may already have arrived. That wastes more transmission work for a larger window, so loss erodes its throughput advantage.

static void packet_set_checksum(Packet *packet) {
    uint8_t buffer[PACKET_MAX_SIZE];
    size_t i;

static uint32_t extract_u32_be(const uint8_t *buf, size_t offset) {
    return ((uint32_t)buf[offset] << 24) |
           ((uint32_t)buf[offset + 1u] << 16) |
           ((uint32_t)buf[offset + 2u] << 8) |
           (uint32_t)buf[offset + 3u];
}

uint16_t packet_checksum(const uint8_t *data, size_t length) {
    uint32_t sum = 0u;
    size_t i = 0u;
    // GCOVR_EXCL_START
    if (data == NULL) {
        return 0u;
    }
    // GCOVR_EXCL_STOP

    for (i = 0u; i + 1u < length; i += 2u) {
        sum += ((uint32_t)data[i] << 8) | (uint32_t)data[i + 1u];
    }
    if ((length & 1u) != 0u) {
        sum += ((uint32_t)data[length - 1u]) << 8;
    }

    return (uint16_t)(~fold_sum(sum));
}

bool packet_decode(const uint8_t *buffer, size_t length, Packet *packet) {
    uint16_t expected_checksum;
    uint8_t scratch[PACKET_MAX_SIZE];
    size_t payload_len;

    // GCOVR_EXCL_START
    if (buffer == NULL || packet == NULL) {
        return false;
    }
    // GCOVR_EXCL_STOP
    if (length < PACKET_HEADER_SIZE || length > PACKET_MAX_SIZE) {
        return false;
    }

    payload_len = (size_t)extract_u16_be(buffer, 8);
    // GCOVR_EXCL_START
    if (payload_len > PACKET_MAX_PAYLOAD) {
        return false;
    }
    // GCOVR_EXCL_STOP
    if (length != PACKET_HEADER_SIZE + payload_len) {
        return false;
    }
    if (buffer[0] > PACKET_TYPE_FIN || buffer[1] != 0u) {
        return false;
    }

    expected_checksum = extract_u16_be(buffer, 2);
    memcpy(scratch, buffer, length);
    scratch[2] = 0u;
    scratch[3] = 0u;
    if (packet_checksum(scratch, length) != expected_checksum) {
        return false;
    }

    packet->type = buffer[0];
    packet->reserved = buffer[1];
    packet->checksum = expected_checksum;
    packet->seq = extract_u32_be(buffer, 4);
    packet->length = (uint16_t)payload_len;
    memcpy(packet->payload, buffer + PACKET_HEADER_SIZE, payload_len);
    return true;
}

bool receiver_on_packet(ReceiverState *state, const Packet *packet,
                       uint32_t *ack_seq, uint8_t *out_payload,
                       size_t *out_length, bool *delivered) {

        out_payload == NULL || out_length == NULL || delivered == NULL) {

    *out_length = 0u;

        if (packet->seq == state->expected) {
            payload_len = packet->length;
            // GCOVR_EXCL_START
            if (payload_len > PACKET_MAX_PAYLOAD) {
                payload_len = PACKET_MAX_PAYLOAD;

            memset(out_payload + payload_len, 0, PACKET_MAX_PAYLOAD - payload_len);

        if (packet->seq == state->expected) {
            state->expected += 1u;
            state->finished = true;
            state->should_linger = true;
            state->last_ack = state->expected;
            *ack_seq = state->expected;
            *delivered = false;
            return true;
        }
        state->last_ack = state->expected;
        *ack_seq = state->expected;
        return true;
    }

    // GCOVR_EXCL_START
    if (packet->type == PACKET_TYPE_ACK) {
        *ack_seq = packet->seq;
        return true;
    }

    *ack_seq = state->expected;
    return true;
    // GCOVR_EXCL_STOP
}

static bool valid_session(const char *session) {
    size_t len;
    if (session == NULL || *session == '\0') {
        return false;
    }
    len = strlen(session);
    if (len < 1u || len > 32u) {
        return false;
    }

static bool valid_rate(double value) {

static int resolve_address(const char *host, int port, struct sockaddr_storage *ss, socklen_t *len) {
    struct addrinfo hints;
    struct addrinfo *result = NULL;
    char service[32];
    int rc;

    memset(&hints, 0, sizeof(hints));
    hints.ai_family = AF_UNSPEC;
    hints.ai_socktype = SOCK_DGRAM;
    hints.ai_flags = 0;

    snprintf(service, sizeof(service), "%d", port);
    rc = getaddrinfo(host, service, &hints, &result);
    if (rc != 0) {
        fprintf(stderr, "getaddrinfo: %s\n", gai_strerror(rc));
        return -1;
    }
    memcpy(ss, result->ai_addr, result->ai_addrlen);
    *len = (socklen_t)result->ai_addrlen;
    freeaddrinfo(result);
    return 0;
}

static int hello_and_wait(int sockfd, const char *session, bool is_sender,
                          double loss, double corrupt, double dup,
                          const struct sockaddr *peer, socklen_t peer_len) {
    char msg[256];
    char reply[512];
    int attempts = 0;

    if (is_sender) {
        snprintf(msg, sizeof(msg), "HELLO %s send %.6f %.6f %.6f", session, loss, corrupt, dup);
    } else {
        snprintf(msg, sizeof(msg), "HELLO %s recv", session);
    }

    while (attempts < 5) {
        ssize_t sent = sendto(sockfd, msg, strlen(msg), 0, peer, peer_len);
        struct pollfd pfd;
        int poll_rc;

        if (sent < 0) {
            perror("sendto");
            return 2;
        }

        pfd.fd = sockfd;
        pfd.events = POLLIN;
        pfd.revents = 0;
        poll_rc = poll(&pfd, 1u, 1000);
        if (poll_rc <= 0) {
            ++attempts;
            continue;
        }

        memset(reply, 0, sizeof(reply));
        ssize_t received = recvfrom(sockfd, reply, sizeof(reply) - 1u, 0, NULL, NULL);
        if (received <= 0) {
            ++attempts;
            continue;
        }
        reply[received] = '\0';
        if (strncmp(reply, "OK", 2) == 0) {
            return 0;
        }
        if (strncmp(reply, "ERR ", 4) == 0) {
            fprintf(stderr, "%s\n", reply);
            return 2;
        }
        ++attempts;
    }

    fprintf(stderr, "relay failed to reply\n");
    return 2;
}

static uint64_t now_ms(void) {
    struct timespec ts;
    if (clock_gettime(CLOCK_MONOTONIC, &ts) != 0) {
        return 0u;
    }
    return (uint64_t)ts.tv_sec * 1000u + (uint64_t)(ts.tv_nsec / 1000000u);
}

static int transmit_packets(int sockfd, const struct sockaddr_storage *relay_addr,
                            socklen_t relay_len, const Packet *packets, size_t count) {
    for (size_t i = 0u; i < count; ++i) {
        uint8_t wire[PACKET_MAX_SIZE];
        size_t written = 0u;
        if (!packet_encode(&packets[i], wire, sizeof(wire), &written)) {
            fprintf(stderr, "cannot encode packet\n");
            return -1;
        }
        if (sendto(sockfd, wire, written, 0,
                   (const struct sockaddr *)relay_addr, relay_len) != (ssize_t)written) {
            perror("sendto");
            return -1;
        }
    }
    return 0;
}

static int sender_mode(const char *relay, const char *session, const char *file_path,
                      uint32_t window, uint32_t timeout_ms,
                      double loss, double corrupt, double dup, int port) {
    struct sockaddr_storage relay_addr;
    socklen_t relay_len = 0;
    int sockfd;
    FILE *fp;
    uint8_t *data = NULL;
    size_t file_size = 0u;
    SenderState sender;
    uint64_t deadline_ms = 0u;
    int exit_code = 2;
    uint8_t recv_buf[2048];

    if (resolve_address(relay, port, &relay_addr, &relay_len) != 0) {
        return 2;
    }

    sockfd = socket(relay_addr.ss_family, SOCK_DGRAM, 0);
    if (sockfd < 0) {
        perror("socket");
        return 2;
    }

    fp = fopen(file_path, "rb");
    if (fp == NULL) {
        perror(file_path);
        close(sockfd);
        return 2;
    }
    if (fseek(fp, 0L, SEEK_END) != 0) {
        perror("fseek");
        fclose(fp);
        close(sockfd);
        return 2;
    }
    long size = ftell(fp);
    if (size < 0) {
        perror("ftell");
        fclose(fp);
        close(sockfd);
        return 2;
    }
    rewind(fp);
    file_size = (size_t)size;
    data = (uint8_t *)malloc(file_size == 0u ? 1u : file_size);
    if (data == NULL) {
        fclose(fp);
        close(sockfd);
        return 2;
    }
    if (file_size > 0u) {
        if (fread(data, 1u, file_size, fp) != file_size) {
            perror("fread");
            free(data);
            fclose(fp);
            close(sockfd);
            return 2;
        }
    }
    fclose(fp);

    sender_init(&sender, window, timeout_ms);
    sender_set_file(&sender, data, file_size);
    if (sender.copy == NULL) {
        fprintf(stderr, "unable to allocate sender packet buffer\n");
        free(data);
        close(sockfd);
        return 2;
    }

    if (hello_and_wait(sockfd, session, true, loss, corrupt, dup,
                       (const struct sockaddr *)&relay_addr, relay_len) != 0) {
        free(data);
        close(sockfd);
        return 2;
    }

    deadline_ms = 0u;
    while (!sender.done) {
        Packet packet_list[64];
        size_t count = 0u;
        int timeout_ms_left;
        struct pollfd pfd;
        ssize_t received;

        count = sender_ready_packets(&sender, packet_list,
                                     sizeof(packet_list) / sizeof(packet_list[0]));
        if (count > 0u) {
            if (transmit_packets(sockfd, &relay_addr, relay_len, packet_list, count) != 0) {
                break;
            }
            if (deadline_ms == 0u) {
                deadline_ms = now_ms() + sender.timeout_ms;
            }
        }

        if (sender.base < sender.next) {
            uint64_t now = now_ms();
            if (now >= deadline_ms) {
                count = sender_on_timeout(&sender, packet_list,
                                         sizeof(packet_list) / sizeof(packet_list[0]));
                if (count > 0u &&
                    transmit_packets(sockfd, &relay_addr, relay_len, packet_list, count) != 0) {
                    break;
                }
                deadline_ms = sender.done ? 0u : now_ms() + sender.timeout_ms;
                continue;
            }
            timeout_ms_left = (int)(deadline_ms - now);
        } else {
            fprintf(stderr, "sender has no outstanding packet but is not complete\n");
            break;
        }

        pfd.fd = sockfd;
        pfd.events = POLLIN;
        pfd.revents = 0;
        int poll_result = poll(&pfd, 1u, timeout_ms_left);
        if (poll_result < 0) {
            if (errno == EINTR) {
                continue;
            }
            perror("poll");
            break;
        }
        if (poll_result == 0) {
            continue;
        }

        received = recvfrom(sockfd, recv_buf, sizeof(recv_buf), 0, NULL, NULL);
        if (received < 0) {
            if (errno == EINTR) {
                continue;
            }
            perror("recvfrom");
            break;
        }
        if (received == 0) {
            continue;
        }

        Packet incoming;
        if (!packet_decode(recv_buf, (size_t)received, &incoming)) {
            continue;
        }
        if (incoming.type == PACKET_TYPE_ACK) {
            uint32_t old_base = sender.base;
            sender_on_ack(&sender, incoming.seq);
            if (sender.base > old_base && !sender.done) {
                deadline_ms = now_ms() + sender.timeout_ms;
            }
        }
    }

    if (sender.done && sender.base == sender.total_packets + 1u) {
        exit_code = 0;
    } else if (sender.done && sender.timeout_count >= 10u) {
        fprintf(stderr, "transfer failed after 10 consecutive timeouts\n");
    }

    sender_release(&sender);
    free(data);
    close(sockfd);
    return exit_code;
}

static int receiver_mode(const char *relay, const char *session, const char *file_path, int port) {
    struct sockaddr_storage relay_addr;
    socklen_t relay_len = 0;
    int sockfd;
    FILE *out;
    ReceiverState receiver;
    uint8_t recv_buf[2048];
    uint64_t last_activity;
    int exit_code = 2;

    if (resolve_address(relay, port, &relay_addr, &relay_len) != 0) {
        return 2;
    }
    sockfd = socket(relay_addr.ss_family, SOCK_DGRAM, 0);
    if (sockfd < 0) {
        perror("socket");
        return 2;
    }
    out = fopen(file_path, "wb");
    if (out == NULL) {
        perror(file_path);
        close(sockfd);
        return 2;
    }

    if (hello_and_wait(sockfd, session, false, 0.0, 0.0, 0.0,
                       (const struct sockaddr *)&relay_addr, relay_len) != 0) {
        fclose(out);
        close(sockfd);
        return 2;
    }

    receiver_init(&receiver);
    last_activity = now_ms();
    while (1) {
        struct pollfd pfd;
        int poll_rc;
        ssize_t received;
        Packet packet;
        uint8_t payload[PACKET_MAX_PAYLOAD];
        size_t payload_len = 0u;
        bool delivered = false;
        uint32_t ack_seq = 0u;
        uint8_t wire[PACKET_MAX_SIZE];
        size_t written = 0u;
        uint64_t now = now_ms();
        uint64_t idle_ms = now - last_activity;
        int poll_timeout = idle_ms >= 30000u ? 0 : (int)(30000u - idle_ms);

        pfd.fd = sockfd;
        pfd.events = POLLIN;
        pfd.revents = 0;
        poll_rc = poll(&pfd, 1u, poll_timeout);
        if (poll_rc < 0) {
            if (errno == EINTR) {
                continue;
            }
            perror("poll");
            break;
        }
        if (poll_rc == 0) {
            fprintf(stderr, "receiver timeout\n");
            break;
        }

        received = recvfrom(sockfd, recv_buf, sizeof(recv_buf), 0, NULL, NULL);
        if (received <= 0) {
            continue;
        }
        if (!packet_decode(recv_buf, (size_t)received, &packet)) {
            continue;
        }
        last_activity = now_ms();

        if (receiver_on_packet(&receiver, &packet, &ack_seq, payload, &payload_len, &delivered)) {
            if (delivered && payload_len > 0u) {
                fwrite(payload, 1u, payload_len, out);
            }
            Packet ack;
            memset(&ack, 0, sizeof(ack));
            ack.type = PACKET_TYPE_ACK;
            ack.seq = ack_seq;
            ack.length = 0u;
            ack.reserved = 0u;
            if (!packet_encode(&ack, wire, sizeof(wire), &written)) {
                continue;
            }
            if (sendto(sockfd, wire, written, 0,
                       (const struct sockaddr *)&relay_addr, relay_len) != (ssize_t)written) {
                perror("sendto");
                break;
            }
            if (packet.type == PACKET_TYPE_FIN && receiver.finished) {
                exit_code = 0;
                uint64_t linger_until = now_ms() + 2000u;
                while (now_ms() < linger_until) {
                    struct pollfd linger_pfd;
                    int remaining = (int)(linger_until - now_ms());
                    linger_pfd.fd = sockfd;
                    linger_pfd.events = POLLIN;
                    linger_pfd.revents = 0;
                    int ready = poll(&linger_pfd, 1u, remaining);
                    if (ready < 0) {
                        if (errno == EINTR) {
                            continue;
                        }
                        perror("poll");
                        exit_code = 2;
                        break;
                    }
                    if (ready == 0) {
                        break;
                    }

                    received = recvfrom(sockfd, recv_buf, sizeof(recv_buf), 0, NULL, NULL);
                    if (received < 0) {
                        if (errno == EINTR) {
                            continue;
                        }
                        perror("recvfrom");
                        exit_code = 2;
                        break;
                    }
                    if (packet_decode(recv_buf, (size_t)received, &packet) &&
                        packet.type == PACKET_TYPE_FIN &&
                        packet.seq + 1u == receiver.expected) {
                        if (sendto(sockfd, wire, written, 0,
                                   (const struct sockaddr *)&relay_addr, relay_len) != (ssize_t)written) {
                            perror("sendto");
                            exit_code = 2;
                            break;
                        }
                    }
                }
                fclose(out);
                close(sockfd);
                return exit_code;
            }
        }
    }

    fclose(out);
    close(sockfd);
    return exit_code;
}

    for (unsigned step = 0u; step < 1000u && !sender.done; ++step) {
      size_t count = sender_ready_packets(&sender, packets,
                                          sizeof(packets) / sizeof(packets[0]));
      if (count == 0u) {
        if (sender.base < sender.next) {
          count = sender_on_timeout(&sender, packets,
                                    sizeof(packets) / sizeof(packets[0]));
